QH VisionX Notepad
Notepad فارسی/RTL، کاملاً استاتیک و مناسب GitHub Pages و Netlify.
امکانات: چند یادداشت، ذخیره خودکار LocalStorage، جستجو، ویرایش ساده، Bold/Italic/Underline، لیست، کپی، دانلود TXT، چاپ، Dark/Light، میانبرهای صفحه‌کلید و رابط موبایل.
برای اجرا index.html را باز کنید. برای GitHub Pages فایل‌ها را در repository قرار دهید و Pages را فعال کنید. برای Netlify، پوشه را به Netlify Drop بکشید.
